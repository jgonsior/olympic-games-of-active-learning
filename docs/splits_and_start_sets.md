# Splits & Start Sets

OGAL uses pre-generated train/test splits and start sets to ensure reproducibility across all 4.6M experiments.

---

## Train/test splits

- **5 splits** per dataset (controlled by `DATASETS_AMOUNT_OF_SPLITS`)
- **40% test** holdout (controlled by `DATASETS_TEST_SIZE_PERCENTAGE`)
- Generated by `00_download_datasets.py` and stored as `{dataset}_split.csv`

## Start sets

- **10,000 candidate start sets** generated per dataset (`AMOUNT_OF_START_POINTS_TO_GENERATE`)
- The paper uses indices 0–19 (`EXP_GRID_START_POINT: [0-19]`)
- Each start set defines the initial labeled pool before the AL loop begins

## In experiment configs

```yaml
EXP_GRID_TRAIN_TEST_BUCKET_SIZE: [0, 1, 2, 3, 4]   # 5 splits
EXP_GRID_START_POINT: [0-19]                          # 20 start sets
```

The OPARA archive already contains all pre-computed splits, so you only need to regenerate them if adding new datasets.
