# Reference

Compact technical reference for OGAL internals. For hands-on instructions see
[Run & reproduce](run.md); for output files see [Results & evaluation](results.md).

---

## Configuration

All configuration is loaded by `misc/config.py` in this priority order (highest wins):

1. **CLI arguments** — `--KEY value`
2. **`.server_access_credentials.cfg`** — INI file with `[LOCAL]` and `[HPC]` sections (copy from `.server_access_credentials.cfg.example`)
3. **`resources/exp_config.yaml`** — named experiment grids (`EXP_GRID_*` keys)
4. **Workload row** — when `WORKER_INDEX` is set, the matching row from `01_workload.csv` overrides per-experiment keys
5. **Built-in defaults**

### What you typically set

| Key | Where | Purpose |
|-----|-------|---------|
| `OUTPUT_PATH` | `.server_access_credentials.cfg` `[LOCAL]` | Directory for all experiment output |
| `DATASETS_PATH` | `.server_access_credentials.cfg` `[LOCAL]` | Directory containing preprocessed dataset CSVs |
| `EXP_TITLE` | CLI | Selects the experiment block in `exp_config.yaml` and sets the output subdirectory |
| `WORKER_INDEX` | CLI | Runs a single row from the generated workload |

### Experiment grid keys (`resources/exp_config.yaml`)

`01_create_workload.py` expands these into one row per combination:

| Key | Type | Description |
|-----|------|-------------|
| `EXP_GRID_DATASET` | `List` | Dataset names or IDs |
| `EXP_GRID_STRATEGY` | `List` | AL strategy names or IDs |
| `EXP_GRID_LEARNER_MODEL` | `List` | Learner model names (default: `[RF]`) |
| `EXP_GRID_BATCH_SIZE` | `List[int]` | Samples queried per AL cycle (default: `[5]`) |
| `EXP_GRID_START_POINT` | `List[int]` | Start-set indices; supports `[0-19]` range syntax |
| `EXP_GRID_TRAIN_TEST_BUCKET_SIZE` | `List[int]` | Split indices (default: `[0,1,2,3,4]`) |
| `EXP_GRID_RANDOM_SEED` | `List[int]` | Per-experiment random seeds |

### HPC / SLURM keys

Only needed when `RUNNING_ENVIRONMENT=hpc`. Set in the `[HPC]` section of `.server_access_credentials.cfg`:

`SSH_LOGIN`, `WS_PATH`, `PYTHON_PATH`, `OUTPUT_PATH`, `DATASETS_PATH`, `SLURM_PROJECT`, `SLURM_MAIL`.

SLURM job parameters (`SLURM_TIME_LIMIT`, `SLURM_MEMORY`, `SLURM_NR_THREADS`, …) have sensible defaults — see `resources/exp_config.yaml` for the full list.

## Data sources

OGAL covers **92 tabular classification datasets** from two sources:

| Source | Config file | Credentials |
|--------|-------------|-------------|
| OpenML | `resources/openml_datasets.yaml` | None required |
| Kaggle | `resources/kaggle_datasets.yaml` | Requires `~/.kaggle/kaggle.json` API token |

`00_download_datasets.py` fetches datasets from these sources. The OPARA archive already contains all pre-computed splits, so downloading is only needed if you are regenerating datasets from scratch.

The full dataset list is in `dataset_list.txt`.

---

## Splits & start sets

Each dataset has pre-generated train/test splits and start sets for reproducibility:

- **5 train/test splits** per dataset (40% test holdout) — stored as `{dataset}_split.csv`
- **10,000 candidate start sets** per dataset — the paper uses indices 0–19
- Both are generated by `00_download_datasets.py` and are included in the OPARA archive

In experiment configs these map to `EXP_GRID_TRAIN_TEST_BUCKET_SIZE` (split index) and `EXP_GRID_START_POINT` (start-set index).

## Determinism

OGAL has two seed knobs:

| Seed | Config key | Default | Scope |
|------|-----------|---------|-------|
| Global | `RANDOM_SEED` | `1312` | Set once at process start; pass `-1` to disable |
| Per-experiment | `EXP_RANDOM_SEED` | from `EXP_GRID_RANDOM_SEED` | Re-seeded before each AL loop |

**Key caveats:**

- `RandomForestClassifier` uses parallel tree building — results may vary across hardware.
- MLP/Adam solver output can differ across platforms and BLAS versions.
- Re-running `00_download_datasets.py` on a fresh machine may produce different splits. Use the [OPARA archive](index.md) for the paper's exact splits.
- One framework (scikit-activeml) uses the global seed instead of the per-experiment seed.
