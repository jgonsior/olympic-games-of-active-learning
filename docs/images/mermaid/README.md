# Pre-rendered Mermaid Diagrams

Static SVG fallbacks for Mermaid diagrams, auto-generated by [`scripts/render_mermaid.py`](https://github.com/jgonsior/olympic-games-of-active-learning/blob/main/scripts/render_mermaid.py) during CI/CD.

**Naming:** `{source-file}-{md5-hash}.svg`

**Local generation:**

```bash
npm install -g @mermaid-js/mermaid-cli
python scripts/render_mermaid.py
```

SVGs are regenerated on each build. Modified diagrams get new hashes automatically.
